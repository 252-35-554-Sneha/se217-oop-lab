## Week 02: Java Basic Syntax Practice

The programs in `week02/src` are implemented based on the **Java Basic Syntax Bangla Tutorial** series by *Bangla Coding Tutor*.

| File Name | Lecture Topic | Description |
| :--- | :--- | :--- |
| `PrintBasics.java` | Print Statements (Lec 02) | `println`, `print`, escape sequences (`\n`, `\t`, `\"`), formatted printing (`printf`) |
| `DataTypesAndVariables.java` | Variables & Types (Lec 03) | Variable declaration, initialization, naming conventions, basic arithmetic |
| `PrimitiveDataTypes.java` | Primitives & Casting (Lec 04) | `byte`, `short`, `int`, `long`, `float`, `double`, `char`, `boolean`, implicit/explicit casting |
| `ConditionIfElse.java` | If-Else Condition (Lec 05) | Even/Odd detection, positive/negative check, voting eligibility |
| `ConditionElseIf.java` | Else-If Ladder (Lec 06) | Grading system scale (A+, A, B, C, F), maximum of three numbers |
| `SwitchCaseDemo.java` | Switch-Case (Lec 07) | Day of week mapping, vowel/consonant grouping, simple arithmetic calculator |
| `OperatorsDemo.java` | Operators & Precedence (Lec 08) | Arithmetic, relational, logical (`&&`, `\|\|`, `!`), pre/post increment/decrement (`++`, `--`) |
| `ForLoopDemo.java` | For Loop (Lec 09) | Counter loop, sum of series (1 to 10), multiplication table, countdown |
| `WhileLoopDemo.java` | While Loop (Lec 10) | While loop condition, sum of digits of a number, number reversing |
| `DoWhileLoopDemo.java` | Do-While Loop (Lec 11) | At-least-once execution guarantee, simulated menu iteration |
| `NestedLoopsPattern.java` | Nested Loops (Lec 12) | Right-angle star triangle, inverted triangle, number triangle, 2D matrix grid |
| `ArrayBasics.java` | 1D Array (Lec 13) | Array allocation, traversal with for & for-each, sum, average, min/max search |
| `TwoDArrayDemo.java` | 2D Array / Matrix (Lec 14) | 3x3 matrix layout, row-wise sum, grand total, diagonal element extraction |
| `StringBasics.java` | String Methods (Lec 15) | `length()`, `charAt()`, `substring()`, `toUpperCase()`, `toLowerCase()`, `equals()`, `contains()` |
| `StringSplitDemo.java` | String Split (Lec 16) | `split()` by space delimiter, parsing CSV records, regex delimiter handling |
| `ScannerInputDemo.java` | User Input (Lec 17) | `Scanner` reading integers, doubles, words, strings, buffer flushing |
| `MethodsDemo.java` | Methods / Functions (Lec 18) | Method declaration, parameters, return types, static methods, method overloading |
| `MethodExercises.java` | Method Exercises (Lec 19) | Modular solutions for Prime Check, Factorial, Power (`base^exp`), and GCD |

## How to Compile and Run

To compile and run any program, open a terminal in the `week02/src` directory:

```bash
# Compile a specific file:
javac PrintBasics.java

# Run the compiled bytecode:
java PrintBasics

# Compile all files at once:
javac *.java
```
